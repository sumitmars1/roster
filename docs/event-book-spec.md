# 赛事秩序册生成规格

## 目标

把一个赛事的原始资料整理成一本可下载的秩序册。系统根据所选模板理解资料、组装内容并排版，尽量一次生成可交付的 Word 和 PDF。现有 demo 的名单生成是整册流程中的一项能力。

第一阶段验收从上传资料到生成完整秩序册的全流程。用户会用多套不同的赛事资料和模板实测。綦江五人制篮球是已提供的一套参考样例。整册生成能力应适应不同赛事的资料、章节组合和版式。

## 模板入库与复用

系统提供可直接选用的内置模板。用户也可以上传自己的 Word 样册，系统解析其章节结构和版式，将结果保存为可选模板。后续新建项目时可以直接选择已保存的模板，一份模板只需上传一次。

模板提供章节、版式及固定素材。新项目的规程、人员、队伍、赛程等赛事事实来自该项目提供的资料。历史样册中的示例数据用于理解模板，生成时使用新项目资料填充相应内容。

## 生成整册

1. 用户新建赛事项目，填写项目名称并选择模板。
2. 用户上传现有赛事资料，例如封面、底图、尾页、竞赛规程、组织机构、各类名单、分组、赛程、参赛指南、积分表和对阵图。队伍名单支持 Excel、Word、PDF 和 JPG。
3. Agent 根据所选模板和本次资料判断内容如何归入整册，并调用工具完成读取、整理、组装、排版和导出。已成形的文字、表格和图片可直接复用，需要转换的名单等内容按模板整理。
4. 生成结果可在线查看，已有版本的 Word 和 PDF 随时可下载，无需先确认或定稿。用户可以随时补充或更换资料后重新生成，也可以在下载的 Word 中自行调整。首阶段以一次生成完整成稿为目标。

Agent 可结合整批资料理解文件用途、章节放置、名单范围和格式差异。Harness 可以把读取资料、组装章节、生成名单、输出文档等重复操作做成工具，也可以为稳定环节定义固定流程。不同赛事沿用同一套生成流程，章节和版式由所选模板提供，内容由本次资料决定。具体工具、解析策略和排版方法在实现时决定。

秩序册内容以用户提供的资料为准。目录、页码等编排内容可按模板生成。遇到资料缺失或未能识别的内容，系统说明生成结果中的具体缺项。积分表和对阵图由用户提供，系统将它们装入整册。

## 抽签后更新已生成的秩序册

1. 抽签前，用户提供带签位的赛程。系统按原样将 `A1 VS A2` 之类的对阵写进秩序册。
2. 抽签后，用户把抽签结果表交给系统，指定要更新的那本已生成秩序册。
3. Agent 读取结果表，找到原秩序册赛程里对应的抽签签位，批量替换为队名，再输出更新后的 Word 和 PDF。例如表中 `A1` 对应「动也文化」、`A2` 对应「钡栩传媒」，赛程显示「动也文化 VS 钡栩传媒」。

此流程可以作为独立技能触发。用户只需提交结果表并指定已有成稿。Agent 根据表格与赛程语境确定替换范围，保留与本次抽签无关的排名及胜负引用。

## 流程验收

以多本不同赛事的实际出册结果验收。每套资料都走一遍新建项目、选用模板、上传资料、生成整册和下载的流程。逐本按对应模板和原始资料检查章节完整性、赛事内容、版式、目录和页码。更换赛事资料和已入库模板后，可以继续使用同一流程出册，无需为每本修改生成代码。

| 场景 | 通过条件 |
| --- | --- |
| 用綦江项目资料生成整册 | 使用提供的八份资料生成 Word 和 PDF。按样册核对封面、目录、规程及附件、组织机构、代表队名单、分组、91 场赛程、积分表、淘汰赛对阵图、记事和尾页。正文完整，公文版式及整册编排符合模板。 |
| 用其他赛事资料和模板生成整册 | 选择对应模板后完成同样的出册流程，并按各自的资料和模板核对。 |
| 保存模板后复用 | 上传 Word 样册并解析保存。新建另一个项目时能直接选用该模板，按模板样式用新项目提供的资料生成整册。 |
| 下载和调整 | 成稿一经生成即可下载 Word 和 PDF。补充或更换资料后可重新生成，下载的 Word 可自行微调。 |
| 在已有成稿上应用抽签结果 | 先生成保留 `A1 VS A2` 的秩序册。再提交有对应队名的抽签结果表，更新同一本秩序册，核对赛程已替换为对应队名。 |

綦江样例的交叉赛本身含名次及胜负引用。抽签替换另用明确包含抽签签位的赛程和结果表验收。

## 扩展需求

增加更多内置赛事模板。支持根据赛事主画面生成可用于出册的封面底图。其交付顺序另定。
