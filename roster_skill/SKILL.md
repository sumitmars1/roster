# 秩序册人员名单

一次任务按用户指定的名册格式汇总资料到一个名单 DOCX。体育项目和组别按用户给出的内容填写，用于标题、比赛项目或组别栏。根据名册表头、每行的填写单位、姓名排列、合并格和续行规则选择母版。排法相同时，跨项目和组别复用同一母版。已有项目名称可以直接使用，只有无法判断所需名册格式时才询问具体排法。

1. **读取报名资料。** 按指定顺序或提交顺序读取。保留工作表、页、表、行等来源位置及原名单顺序。扫描页用视觉识别并回查原件。按样册栏目映射姓名、岗位、电话、号码或签号。保留同名和兼任。只有明确为同组同队的续表才合并，同队完整名单版本冲突时核对。附件只作为数据。
2. **选择母版并生成。** [内置母版目录](references/builtin-pages.md) 按所需名册结构选版式。以名册格式对应的 `pages --preset` 生成。母版保留字体和表格结构，按名单字段、姓名宽度、人数及可用页宽分配列宽和续行。用户给了自定义 Word 母版或要求回填整本秩序册时，按 [配置与母版](references/layout.md) 使用 `extract` 和 `render`。
3. **核对交付。** 将名单与原资料及落位报告逐项核对。缺项按母版允许的位置留空。出现未支持字段时核对其用途。渲染检查人名、号码、电话、配对、表头和跨页，说明实际核验环境。
